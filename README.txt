FOTOBOX Android v2 – zdrojový projekt

Změny:
- systémový Android výběr fotografií (OPEN_DOCUMENT)
- možnost vybrat více fotografií
- originální fotoaparát telefonu přes ACTION_IMAGE_CAPTURE
- po výběru/vyfocení se snímek vrací do FOTOBOXU
- živá dlaždice v hlavičce FOTOBOXU střídá fotografie označené jako Oblíbené
- středové tlačítko je Foťák pouze na Domů; mimo Domů slouží jako AI úprava

Projekt je připraven pro Android Studio / Gradle.
